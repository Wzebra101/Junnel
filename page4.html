CSS Selector

Pick the right player for the right play.

What Is a Selector?

A CSS selector chooses which HTML elements get styled. It works like a coach calling a play: you can send the whole team, one position, or a single star player.

Learning the right selector means you can style exactly the element you want, nothing more and nothing less.

The Selector Playbook

Selector Type Example On the Court
Universal * Everyone on the court
Element p Every player in the same position
Class .guard A group of players with the same role
ID #mvp The one-of-a-kind star player
Grouping .guard, .forward Two roles, one play call
Descendant .roster li Anyone inside the team lineup
Child .roster > li Only the direct starters
Adjacent Sibling h3 + p The player standing right next to you
Attribute [data-position="center"] A player with a special tag on the jersey
Pseudo-class li:hover How a player reacts in the moment
Pseudo-element li::after Extra details added around a player

Here is the CSS that styles the starting five:

.roster > li { border: 3px solid navy; }
.roster .guard { background: navy; }
.roster .forward { background: #ffe3cc; }
#mvp { background: orange; }
[data-position="center"]::after { content: " (Team MVP)"; }
.roster li:first-child { border-left-width: 14px; }
.roster li:nth-child(even) { border-style: dashed; }
.roster li:hover { transform: translateX(8px); }

Conclusion

Selectors are the playbook of CSS. A universal selector reaches the whole team, a class reaches a position, and an ID finds the one star on the floor. Choosing the right one keeps your code clean and your page looking sharp.

Right selector, right play.
