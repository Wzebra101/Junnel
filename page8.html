Task Overview

The Performance Task is the championship game of this project. The goal is to build a complete basketball-themed website using only HTML and CSS, with every page sharing the same header, footer, and navigation.

Seven pages were styled with internal CSS, written inside a style tag. This final page does something different: all of its styling comes from one external file called styles.css.

Skills Checklist

Here is every skill this project put on the floor.

  • A full page structure with a header, main content, and footer
  • Headings, paragraphs, lists, and tables
  • Links, a table of contents, and Previous and Next navigation
  • Internal CSS on pages 1 through 7
  • CSS selectors for choosing exactly the right element
  • CSS borders, including styles, widths, colors, and rounded corners
  • CSS backgrounds, including gradients, repeat, size, and position
  • The CSS box model with margin, border, padding, and content
  • An external stylesheet, styles.css, on this page
